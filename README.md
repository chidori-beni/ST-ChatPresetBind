# ST-ChatPresetBind · 聊天预设绑定

✅ 为每个聊天窗口单独绑定预设配置，打开聊天窗口时自动切换到绑定的预设

✅ 包括【提示词开关状态】【生成参数（温度、top_p 等）】

✅ 每个聊天可保存**多个配置**，支持命名、设为默认、一键应用

✅ 提示词开关、参数调整时，点「更新当前配置」可覆盖当前设置

### 安装：
扩展管理器 → 安装扩展 → 粘贴地址：
```
https://github.com/chidori-beni/ST-ChatPresetBind
```

### 使用方法：
安装后，打开输入框左边的扩展菜单 🪄（魔术棒），点击「聊天预设绑定」

**保存配置：** 调整好预设和开关后，点「保存当前配置」，自动以预设名+时间命名

**管理配置列表：**
- ▶ 应用 — 立即切换到该配置
- 🔄 更新 — 用当前设置覆盖此配置（保留名称）
- ★ 默认 — 设为打开聊天时自动应用的配置
- ✏ 重命名 — 改个好记的名字
- 🗑 删除 — 移除此配置
