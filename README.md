# ST-ChatPresetBind · 聊天预设绑定

为每个聊天窗口单独绑定预设配置，切换聊天时自动恢复。

## 安装

扩展管理器 → 安装扩展 → 粘贴地址：
```
https://github.com/chidori-beni/ST-ChatPresetBind
```

## 使用

1. 打开聊天窗口，调好预设和所有开关
2. 点输入框左侧 扩展菜单（魔术棒） → **聊天预设绑定**
3. 点「**绑定当前配置**」
4. 之后切换回此聊天，自动恢复 ✓

已绑定的聊天再次点击可「**更新当前配置**」，随时覆盖。

## 可绑定的内容

| 选项 | 说明 |
|------|------|
| 预设名称 | 自动切换到绑定的预设 |
| 提示词开关状态 | 各条目启用/禁用 |
| 生成参数 | 温度、top_p 等 |

三项可在面板内分别勾选，按需保存。
